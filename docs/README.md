# OpenPrism2

This is a reboot of OpenPrism. Project north-star goals:

1. **Make a LaTeX editor for those not comfortable with LaTeX.** AI should help with latex and match user intent to LateX output. For example "I need a table of content here.", or "cite". There should be a keystroke to invoke AI within the editor. switch templates with ease.

2. **Everything needed to mangage the work of working together.** People can review papers, edit together in real-time, track each other changes, revert changes, leave notes and todo's.

3. **Research assistant in a box** Help with research activity like finding sources, similar papers, validating citations (appropriate to argument), Rewrite sections, suggest ways to shorten papers, zotero integration.
