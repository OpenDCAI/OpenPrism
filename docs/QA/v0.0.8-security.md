#49 (credential history), #50 (your AI keys stored on the server), #51 (scoped URL tokens), #52 (refresh cookie, access

`integrations.test_userkeys`, `common.test_urltokens`, `accounts.test_cookies`, `projects.test_direct_uploads`.

  **`deploy/garage-init.sh` again**: it now sets the bucket CORS that direct uploads need.

## A. Sessions (#52)

| # | Step | Expected |
|---|---|---|
| 1 | Sign in. Developer tools → Application → Local Storage and Session Storage | No token (nothing starting `eyJ`); `openprism-auth-v1` is gone |
| 2 | Application → Cookies | `openprism_refresh`, HttpOnly, SameSite Strict, path `/api/auth`. In the console `document.cookie` does not show it |
| 3 | Reload; open a second tab of the app | Both signed in |
| 4 | Sign out in one tab | The other tab drops to the sign-in page within a second or two; the cookie is gone |
| 5 | (Upgrade) In a browser signed in with v0.0.7 or earlier, open v0.0.8 | Still signed in; `openprism-auth-v1` is removed |

## B. Links carry scoped tokens only (#51)

## E. AI requests do not hold the server (#47)

| # | Step | Expected |
|---|---|---|
| 1 | Network tab; ask the Assistant, or Ctrl/Cmd+K in the editor | `POST /api/agent/run` returns at once with a `jobId`; then `GET /api/jobs/<id>` every second until the answer |
| 2 | Ctrl/Cmd+K → a request → **Cancel** while it runs | Stops; `POST /api/jobs/<id>/cancel` is sent |

## F. Direct uploads (#53)

| # | Step | Expected |
|---|---|---|
| 1 | Network tab; **Upload files** → a large PDF or image (e.g. 50 MB) | A `PUT` to `localhost:3900` carries the file; requests to `/api/` are small JSON; the status bar shows "Uploading… n%" then "Uploaded 1 files"; the file is in the tree |
