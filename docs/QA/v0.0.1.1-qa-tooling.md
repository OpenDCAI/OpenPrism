# QA: v0.0.1.1 QA tooling

Issues #10 (Playwright, Chromium and Chrome baked into the devcontainer) and #11 (API tests must not delete the built-in
templates from the dev bucket). This release is for developers; there is nothing new in the app.

**Needs:** the devcontainer, the stack and `npm run dev` running.

| # | Step | Expected |
|---|---|---|
| 1 | In the devcontainer: `npx playwright --version` | Prints the version pinned in `.devcontainer/Dockerfile` (`PLAYWRIGHT_VERSION`), equal to `@playwright/test` in `apps/frontend/package.json` |
| 2 | `ls $PLAYWRIGHT_BROWSERS_PATH` | Lists a Chromium build; `google-chrome --version` prints a version |
| 3 | `npm run e2e` from the repo root | The suite runs headless in Chromium without downloading anything |
| 4 | `E2E_BROWSER=chrome npm run e2e -- builtin-templates` | Runs in Google Chrome and passes |
| 5 | `E2E_HEADED=1 xvfb-run -a npm run e2e -- editor-shortcuts` | Runs headed under xvfb and passes |
| 6 | `E2E_BASE_URL=http://localhost:8080 npm run e2e -- builtin-templates` | Runs against the nginx image and passes |
| 7 | Note which templates your dev account has, then run `docker compose run --rm api python manage.py test projects --noinput` | Tests pass |
| 8 | Back in the app, create a project from each built-in template and compile one | The templates are all still there and their files still load (#11: the tests used to wipe them) |
