Issues #42 (restore a single file), #43 (failed compiles saved as versions, with their log), #44 (failed versions in the
Versions panel), #45 (workspace storage report and time-based retention) and #46 (visual PDF comparison).
Automated: `e2e/versions.spec.ts`, `e2e/workspace-storage.spec.ts`, `versions` tests (`test_restore`, `tests`,
`test_retention`, `test_api`, `test_storage`; the real-compile ones under `worker-tex`).

v0.0.4.1 was released after v0.0.7: `curl localhost:8000/healthz` reports `0.0.4.1`, and the app still has every v0.0.7
feature.

**Needs:**
- Migrations applied and the workers restarted, so they run the new code: `docker compose up -d` (the api migrates on
  start), then `docker compose restart worker-tex worker-ai beat`. **Without the restart no compile is saved as a version.**
- An **Owner** account with a team workspace, an **Editor** and a **Viewer** in it (see README), and a second browser
  profile for part A step 6.

## A. Restore a single file (#42)

Set up: a project with `main.tex` (a document that says *Alpha*) and `notes.tex` (*old notes*). Compile (version #1).
Change `main.tex` to say *Beta* and `notes.tex` to *new notes*, add a figure `fig.png`, compile (version #2).

| # | Step | Expected |
|---|---|---|
| 1 | Versions → select **#1** → **Compare** (To: *Current project*) → select `main.tex` | The diff shows Alpha → Beta, and a **Restore this file** button above it |
| 2 | **Restore this file** | It asks "Replace main.tex with its version #1?" with Restore and Cancel |
| 3 | **Restore** | `main.tex` disappears from the changed list and the editor shows *Alpha*; the status bar says "Restored main.tex from version #1" |
| 4 | Close the dialog, open `notes.tex` | Still *new notes*: nothing else changed |
| 5 | Versions list | Still #1 and #2: a single-file restore records no version. The next compile does |
| 6 | Second browser (Editor): open `notes.tex` and keep it open. First browser: Compare #1 → `notes.tex` → Restore this file → Restore | Refused: "Someone has this file open…" with `notes.tex` listed, and nothing is written. Close it in the second browser, **Try again** → restored |
| 7 | Delete `notes.tex`, then Compare #1 → `notes.tex` (*removed*) → Restore this file | It comes back with its #1 text |
| 8 | Compare **#1 → #2** (two versions) | No Restore this file button: it only restores into the current project |
| 9 | As the **Viewer**: Compare | No Restore this file button |

## D. Visual PDF comparison (#46)

page 2 to *Second page says Betadocument instead.*, compile.

| # | Step | Expected |
|---|---|---|
