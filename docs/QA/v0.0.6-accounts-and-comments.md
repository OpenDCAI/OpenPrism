# QA: v0.0.6 Account management and comments

Issues #32–#39: outgoing mail, password reset and change, delete account (and making a member an owner), email
verification and registration modes, invitation mail, invite-link roles and revoking, comments. Automated:
`e2e/accounts.spec.ts`, `e2e/verify-email.spec.ts`, `e2e/invitations.spec.ts`, `e2e/invite-links.spec.ts`,
`e2e/comments.spec.ts`; API tests in `accounts`, `projects.test_workspaces`, `collab`, `comments`.

**Needs:**
- The stack running with **Mailpit**: `docker compose up -d --wait` starts it. Every mail the app sends lands at
  **http://localhost:8025**. Keep that tab open; most parts below read a mail from it.
- After pulling this release: `docker compose exec api python manage.py migrate` (new tables and columns) and
  `docker compose restart worker-ai` (it sends the mail).
- **Owner**, **Editor**, **Commenter** and **Viewer** accounts in a team workspace "QA Lab" (see README), and a project
  "Paper" in it whose `main.tex` has a few lines of text.
- A second browser profile or private window for the two-person parts.
