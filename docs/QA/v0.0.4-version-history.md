# QA: v0.0.4 Version history with diff

Issues #21–#26: a version is saved on every successful compile; list, open, name, delete; compare; restore. Automated:
`e2e/versions.spec.ts`, `versions` tests.

**Needs:** **Owner**, a **Viewer** in the same workspace, and a project with `main.tex`, a `figs/` folder with a PNG
included by `\includegraphics`, and a `.bib`. Two browsers for part F.

## A. Saving versions

| # | Step | Expected |
|---|---|---|
| 1 | Open the project, right rail → **Versions** | "No versions yet" |
| 2 | **Compile PDF** | The status bar says "Saved as version #1"; the list shows #1 with your name and the time |
| 3 | Compile again without changing anything | No new version (still one row) |
| 4 | Change a word, compile | #2 appears at the top |
| 5 | Break the document (e.g. delete `\end{document}`) so no PDF is produced, compile | Compile fails; no new version |
| 6 | Replace the PNG in `figs/` with a different image, compile | A new version (binary changes count) |

## B. Opening an older PDF

| # | Step | Expected |
|---|---|---|
| 1 | Click version #1, open its PDF | The preview shows #1's PDF with a banner saying you are viewing version #1 and a way back |
| 2 | Zoom, use the outline, download the PDF | All work on the old PDF; the download is #1's |
| 3 | Press the way back | The current build returns; banner gone |
| 4 | Open #1's PDF, then compile | The banner disappears and the new build shows |

## C. Naming, deleting, retention

| # | Step | Expected |
|---|---|---|
| 1 | Name #2 "submitted" | The name shows in the list |
| 2 | Try to delete #2 | Refused (or no delete offered) until the name is removed |
| 3 | Remove the name, delete #2 | It disappears; other versions still open |
| 4 | Open #1's PDF in the preview, then delete #1 | The preview leaves the deleted version |
| 5 | As **Viewer**, open the project's Versions | The list and old PDFs are visible; no name, delete or restore controls |
| 6 | (Optional, needs a shell) On a project with 4 unnamed and 1 named version: `docker compose exec api python manage.py shell -c "from projects.models import Project; from versions.retention import prune_project; prune_project(Project.objects.get(pk='<projectId>'), keep=2)"` | The two newest unnamed versions and the named one are left |

## D. Compare

| # | Step | Expected |
|---|---|---|
| 1 | Select an older version → **Compare** (against the current project by default) | A list of changed files marked added / removed / modified; binaries shown as changed |
| 2 | Click a changed `.tex` file | A side-by-side diff: removed lines on the left, added on the right |
| 3 | Pick another version as the other side, then swap the order | The diff flips (added becomes removed) |
| 4 | Compare a version with an identical project | "No differences" |
| 5 | At phone width (resize to ~390 px) | The dialog is usable with no sideways scrolling of the page |

## E. Restore

| # | Step | Expected |
|---|---|---|
| 1 | Select an older version → **Restore** | A confirmation listing what will change and saying a new version will be recorded and nothing is lost |
| 2 | Confirm | The editor shows the old text, the file tree matches (added files gone, removed files back, the old PNG back), and a new version "restored from #K" is at the top |
| 3 | Compile | The PDF matches the old version |
| 4 | Restore the latest version onto an identical project | Nothing changes and no new version |
| 5 | As **Viewer** | No Restore button |

## F. Restore while someone else is editing

| # | Step | Expected |
|---|---|---|
| 1 | Owner creates an invite link (Collaboration panel); open it in a private window (**Guest**) and keep `main.tex` open | Both see each other live |
| 2 | Owner restores a version that changes `main.tex` | Refused with a message naming `main.tex` as open elsewhere; nothing changed (no new version, the guest's text untouched) |
| 3 | Guest closes the tab; Owner presses **Try again** | The restore goes through |
| 4 | Owner restores right after closing their own second tab of the project | It works without waiting a minute (idle rooms are dropped) |
